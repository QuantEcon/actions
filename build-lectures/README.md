# Build Lectures

Builds the lectures with Jupyter Book 1 or mystmd, as the website, the PDF or notebooks, and fails the step where the build would pass with something broken. On Jupyter Book 1 it checks the executed notebooks for tracebacks that would be published, and when the build fails it prints each failing notebook's traceback. It can upload the execution reports.

How to set it up, and every input and output: [the `build-lectures` chapter of the user manual](../docs/user/actions/build-lectures.md).
