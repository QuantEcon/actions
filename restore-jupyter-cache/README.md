# Restore Jupyter Cache

Restores the cache that `build-jupyter-cache` saved, so a pull request or publish build re-executes only the notebooks that changed. It only restores by default, and can also save a cache for the later runs of the same pull request.

How to set it up, and every input and output: [the `restore-jupyter-cache` chapter of the user manual](../docs/user/actions/restore-jupyter-cache.md).
