# Setup LaTeX

Installs TeX Live, or any apt packages you list, on a standard Ubuntu runner, and caches the downloaded packages, so that a later run installs them without waiting on an Ubuntu mirror, which can be slow enough to stall a build for hours.

How to set it up, and every input and output: [the `setup-latex` chapter of the user manual](../docs/user/actions/setup-latex.md).
