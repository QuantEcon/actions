# Restore GitHub Pages from a release

Restores a site that publish-gh-pages attached to one of the repository's GitHub releases. It downloads the release's archive and checksum, checks the archive's SHA-256 before anything is extracted, and extracts the site for publish-gh-pages to deploy again.

How to set it up, and every input and output: [the `restore-gh-pages` chapter of the user manual](../docs/user/actions/restore-gh-pages.md).
