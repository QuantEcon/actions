# Example latex-requirements.txt for QuantEcon lecture builds on a standard
# (non-container) runner. Copy it to your repository root, where
# setup-environment's install-latex step reads it by default
# (latex-requirements-file: 'latex-requirements.txt'), and setup-latex reads
# it when named in its requirements-file input.
#
# Not needed in the QuantEcon containers: LaTeX is pre-installed there,
# install-latex is ignored, and setup-latex installs nothing.
#
# Format: Ubuntu apt package names, separated by spaces or newlines; '#'
# starts a comment anywhere on a line, and blank lines are skipped.
#
# These are the TeX packages and build tools both container images install
# (containers/*/Dockerfile in QuantEcon/actions), without the full image's
# texlive-luatex: the lean image runs its pdflatex builds without it. The
# images also install fonts-freefont-ttf and fonts-dejavu for PDF builds; add
# them here if your build uses those fonts. make is listed because
# jupyter-book's pdflatex builder runs `make all-pdf` in the LaTeX output
# directory. To pin versions (package=version), see
# scripts/check-latex-versions.sh in QuantEcon/actions.
texlive-latex-recommended
texlive-latex-extra
texlive-fonts-recommended
texlive-fonts-extra
texlive-xetex
latexmk
xindy
dvipng
ghostscript
cm-super
make
