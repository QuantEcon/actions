# Example latex-requirements.txt for QuantEcon lecture builds on a standard
# (non-container) runner. Copy it to your repository root, where
# setup-environment's install-latex step reads it by default
# (latex-requirements-file: 'latex-requirements.txt').
#
# Not needed in the QuantEcon containers: LaTeX is pre-installed there and
# install-latex is ignored.
#
# Format: one Ubuntu apt package per line. Blank lines and lines whose first
# character is '#' are skipped. A '#' after a package name is not a comment:
# it is passed to apt-get along with the words after it.
#
# These are the TeX packages and build tools both container images install
# (containers/*/Dockerfile in QuantEcon/actions), without the full image's
# texlive-luatex: the lean image runs its pdflatex builds without it. The
# images also install fonts-freefont-ttf and fonts-dejavu for PDF builds; add
# them here if your build uses those fonts. To pin versions (package=version),
# see scripts/check-latex-versions.sh in QuantEcon/actions.
texlive-latex-recommended
texlive-latex-extra
texlive-fonts-recommended
texlive-fonts-extra
texlive-xetex
latexmk
xindy
dvipng
ghostscript
cm-super
