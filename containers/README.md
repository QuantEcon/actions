# QuantEcon containers

The two container images that QuantEcon lecture builds run in:

| Image | Directory |
|---|---|
| `ghcr.io/quantecon/quantecon`, the full image | [`quantecon/`](quantecon/) |
| `ghcr.io/quantecon/quantecon-build`, the lean image | [`quantecon-build/`](quantecon-build/) |

- Which image to use, what is in each, when they change and how to pin one: [Containers](../docs/user/containers.md), in the user manual.
- How they are built, tested and updated: [CONTAINERS.md](../docs/dev/CONTAINERS.md), in the developer docs.
